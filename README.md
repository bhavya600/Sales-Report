# Power BI Sales Dashboard 📊  

A comprehensive **Power BI dashboard** that analyzes **sales performance**, revenue trends, and key business metrics. This project showcases **data modeling, interactive visualizations, and advanced DAX functions**.

I wanted to share some key takeaways!

🔹 DAX Functions I Mastered:
✅ LastDate & FirstDate – Extracting the most recent and earliest dates from datasets.
✅ Calculate & Related – Applying custom aggregations while maintaining relationships across tables.
✅ Divide & If – Handling calculations with conditional logic.
✅ Edate – Managing date-based calculations effectively.
✅ Var + Return – Structuring DAX formulas for improved readability and efficiency.

🔹 Power BI Features I Explored:
📌 Creating Bins – Grouping data dynamically for better analysis.
📌 Dynamic Visuals with Parameters – Making reports interactive based on slicers.
📌 Bookmarks & Selection Pane – Enhancing user experience with toggle-like functionality.
📌 New Cards with Reference Values – Customizing KPIs with formatting options.
📌 Gauge with Target Settings – Visualizing performance against business goals.
📌 Zoom Slider – Enabling detailed data exploration within charts.
📌 Image Insertion in Tables – Adding brand logos and product images inside tables.
📌 Icons for Performance Indicators – Using conditional logic to color-code key metrics.
📌 Custom Tooltips – Providing additional insights when hovering over visuals.

🔹 Additional Learning:
✅ Efficient Data Modeling – Optimizing relationships for better performance.
✅ Multiple Table Import from Excel – Streamlining the data extraction process.
✅ Advanced Use of Icons & Slicers – Enhancing dashboard design for better storytelling.
